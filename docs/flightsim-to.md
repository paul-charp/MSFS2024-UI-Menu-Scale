**Title:** UI Menu Scale

**Category:** Misc / Tools (MSFS 2024)

**Short description:** Smaller, denser MSFS 2024 menus on 4K and 1440p screens: more on screen, less scrolling. Adjustable in the sim's Settings.

## Description

**Works with SimpleUI** (https://flightsim.to/addon/116742/simpleui-there-i-fixed-msfs-ui-for-you): use both together, SimpleUI cleans up the menus, UI Menu Scale sets their size.

On a 4K screen, MSFS 2024 draws its menus at 2x (1.33x at 1440p): big text, wide margins, lots of scrolling. UI Menu Scale keeps the stock UI exactly as designed and draws it smaller, while still filling the whole screen.

- 4K: 1.5x instead of 2x by default. 1440p: 1x instead of 1.33x. 1080p: unchanged.
- Adjustable in Settings › Accessibility › User interface and font › Menu Scale (mod), in the sim's language. Saved across restarts.
- Menus, world map and notifications. Toolbar, in-game panels and EFB keep their stock size.
- No restyle, no replaced menus: the stock layout, drawn at a different scale.
- Works with SimpleUI (tested with 1.0.11).

## Installation

Extract the zip into your Community folder, so you get `Community/paulcharp-ui-menu-scale/manifest.json`, then start the sim.

## Known limits

- The Menu Scale line works with the mouse only.
- Mods that replace the same stock UI components (TitlePage, Shortcut, Notification_Gameplay, Worldmap_Pin) conflict with this one.
- A sim update that changes these components may need a mod update.
